## How to review

1. Open each case folder under `test-results/s7-parity/human-ab/<case_id>/`.
2. Read `prompt.txt` (goal, audience, slide count, template intent, prompt).
3. Optionally read `preview.txt` (slide titles only — not a substitute for opening the decks).
4. Open `Deck_A.pptx` and `Deck_B.pptx` in PowerPoint (or equivalent). Do **not** try to infer which engine produced which file. Ignore file-size differences.
5. Score **A** and **B independently** on every dimension (1 = poor, 5 = excellent).
6. Mark **Preferred: A | B | Tie** for that case and add comments.
7. Return this completed file. Do not ask Cursor which letter is Native vs Presenton until scoring is done.
