                              DATA FLOW EXAMPLES
================================================================================

EXAMPLE 1: VOICE QUERY ("What's in this repo?")
──────────────────────────────────────────────────────────────────────────────
User speaks in microphone
    ↓
Electron captures audio (Web Audio API)
    ↓
Frontend streams to OpenAI Realtime WebSocket
    ↓
OpenAI transcribes + calls Mentrix system prompt
    ↓
Mentrix LLM decides to use: LATTICE_QUERY tool
    ↓
Frontend receives tool call, sends to backend
    ↓
Backend /api/mentrix/companion/realtime/tool endpoint
    ↓
Permission Broker checks: ✅ OK (read-only tool)
    ↓
Lattice Service analyzes repository structure
    ↓
Returns: files, directories, key modules, dependencies
    ↓
Result sent back to OpenAI Realtime
    ↓
OpenAI generates response text + synthesizes voice
    ↓
Frontend receives audio stream + text
    ↓
Browser plays audio, displays text in chat
    ↓
User hears: "This is a Python FastAPI backend..."

Time: 2-5 seconds (mostly OpenAI latency)


EXAMPLE 2: CODE REVIEW WORKFLOW (Full ForgeLoop)
──────────────────────────────────────────────────────────────────────────────
User: "Review my code for bugs"
    ↓
Backend starts ForgeLoop Orchestrator
    ↓
PHASE 1 - SCOUT
  → Lattice scans changed files
  → Identifies key modules, functions
  → Builds context for review
    ↓
PHASE 2 - PLANNER
  → LLM creates review strategy
  → Prioritizes critical areas
  → Plans check order
    ↓
PHASE 3 - BUILDER
  → Analyzes code quality
  → Checks for bugs, security issues
  → Creates detailed comments
    ↓
PHASE 4 - REVIEW
  → LLM meta-reviews the feedback
  → Ensures constructiveness
  → Approves or flags for revision
    ↓
PHASE 5 - DELIVERY
  → Creates GitHub PR with comments
  → Adds labels/assignees
  → Sends Slack notification
    ↓
User sees artifact board with findings
    ↓
User can approve or request changes

Time: 5-30 seconds (depends on code size)


EXAMPLE 3: PERSONA-DRIVEN RESPONSE
──────────────────────────────────────────────────────────────────────────────
Backend receives: /api/mentrix/runs with goal="help me debug"
    ↓
Creates session with:
  - User ID
  - Project scope
  - Persona: "Mentrix" ← Injected into LLM
  - Persona prompt: Full system instructions
    ↓
Calls LLM with messages:
  - System: "You are Mentrix, ZECT's personal operator..."
  - User: "help me debug"
    ↓
LLM responds as Mentrix character:
  - References available tools (weather, Slack, Lattice)
  - Uses company context (Zinnia, insurance)
  - Offers specific tool-based help
    ↓
Response streamed back to frontend
    ↓
User sees personality-consistent answer

Effect: Responses reflect defined persona
